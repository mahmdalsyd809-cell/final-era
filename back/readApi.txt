القسم	النوع	المسار (Endpoint)	الوصف
المصادقة (Auth)	POST	/api/auth/register	تسجيل مستخدم جديد
POST	/api/auth/login	تسجيل دخول (يُرجع Token)
GET	/api/auth/me	جلب بيانات المستخدم الحالي (🔒)
PUT	/api/auth/me	تحديث بيانات الملف الشخصي (🔒)
المتجر (Store)	GET	/api/store/products	عرض المنتجات (مع بحث وفلترة)
GET	/api/store/products/:id	تفاصيل منتج معين
GET	/api/store/products/featured	المنتجات المميزة (للصفحة الرئيسية)
GET	/api/store/categories	قائمة الفئات وعدد المنتجات
الطلبات (Orders)	POST	/api/orders	إتمام عملية الشراء (Checkout)
GET	/api/orders/my/history	سجل طلبات العميل (🔒)
GET	/api/orders/:id	تتبع طلب معين
لوحة التحكم (Admin)	GET	/api/admin/dashboard	إحصائيات لوحة التحكم (🔒 Admin)
GET	/api/admin/products	إدارة المنتجات (CRUD) (🔒 Admin)
GET	/api/admin/users	إدارة المستخدمين (🔒 Admin)
GET	/api/admin/orders	إدارة الطلبات وتغيير حالتها (🔒 Admin)

powershell
npm install
إضافة البيانات التجريبية (Data Seed): هذا الأمر سيملأ قاعدة البيانات بمنتجات ملابس حقيقية وصور من Unsplash مطابقة للديزاين:
powershell
node src/scripts/seedData.js
تشغيل السيرفر:
powershell
npm run dev
